# Roadmap

Milestones describe outcomes; detailed tasks belong in GitHub Issues. Planned milestones are a proposed sequence, not delivery commitments.

| Milestone | Status | Evidence or intended outcome |
| --- | --- | --- |
| Frontend foundation | Complete | App Router starter page/layout, Tailwind styling, TypeScript, ESLint, npm scripts, and lockfile exist. This does not include a Sidequest UI. |
| Canonical project context | Complete | Product, current architecture, roadmap, decision log, README, and agent guidance are documented. |
| Branch-and-return frontend prototype | Next | Demonstrate a primary sample conversation, creation of a branch from a concept/message, separate exploration, and return to the preserved parent position using local state. |
| Interaction validation | Planned | Evaluate clarity, keyboard access, responsive behavior, and repeated branch/return navigation; add focused checks for implemented behavior. |
| AI and durable history | Future, contingent on validation | Decide response/context handling and storage needs, then implement real AI conversations and saved history. Providers and infrastructure remain undecided. |

No Sidequest product interaction milestone is complete yet. Update milestone status only when implementation evidence supports it.
